Privacy Policy

Last updated: 1 November 2026

Summary

gmail-cleaner is a personal tool that runs only on the owner's own computer. The developer operates no servers for it and receives no data from it.

Google user data the app accesses

When the owner signs in with Google, the app can access, through the Gmail API: message IDs, labels, dates, and the sender and subject headers of messages. It does not read message bodies or attachments.

How the data is used

This information is used only to decide which messages match the cleanup rules the owner has configured, and then, only after the owner confirms, to move those messages to Gmail's Trash. The app does not send email, and it does not permanently delete email.

Storage

  • Sign-in tokens are stored in a file on the owner's own computer, readable only by the owner's user account.
  • The app keeps a local activity log containing rule names, counts and message IDs. It does not record subjects, senders, message contents or tokens.
  • Message headers shown in previews are held in memory while the app runs and are not saved.

Sharing

Google user data is not shared, sold or transferred to anyone. The app contains no analytics, advertising or third-party tracking, and it makes network requests only to Google's own APIs.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Deleting your data and revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's local token file removes the stored sign-in. Messages moved to Trash can be restored from Gmail's Trash for 30 days.

Changes and contact

This policy may be updated as the app changes; the date above shows the latest revision. Questions can be raised by opening an issue on the project's GitHub repository.
