gmail-cleaner

A personal, open-source tool that tidies a Gmail inbox safely.

What it does

gmail-cleaner is a small command-line program that runs on the owner's own Linux computer. It uses the Gmail API to find clutter, such as expired one-time passcodes, promotions, social-network notifications and old newsletters, and moves it to Gmail's Trash after a retention period that the user configures.

How it stays safe

  • It previews matches first (dry-run) and only acts after explicit confirmation.
  • It moves messages to Trash only. It never deletes anything permanently.
  • It never touches starred or important mail, and it skips protected senders and subjects such as receipts and payment notices.
  • It reads only message headers (sender, subject, date, labels), never message bodies.
  • It runs entirely on the user's own computer. No data is sent to any server operated by the developer.

Google permissions used

The tool requests the Gmail permissions gmail.readonly (for previews) and gmail.modify (to move messages to Trash). See the Privacy Policy for how Google user data is handled.
